# Breast Cancer Prediction Model

## Overview
This project is a **Machine Learning-based Breast Cancer Prediction Model** that uses the **Breast Cancer Wisconsin (Diagnostic) Dataset** to classify tumors as **Malignant (Cancerous)** or **Benign (Non-Cancerous)**.

## 📌 Features
- Implements **Multiple ML Models**:
  - Logistic Regression
- **Data Preprocessing**:
  - Feature scaling
  - Encoding categorical values
  - Handling missing values (if any)
- **Performance Evaluation**:
  - Accuracy, Precision, Recall, F1-score
  - Confusion Matrix and Classification Report

## 📂 Files in Repository
- `nousheen_model_1.py` → First ML Model (Random Forest)
- `nousheen_model_2.ipynb` → Jupyter Notebook with all ML Models
- `README.md` → Project Documentation
